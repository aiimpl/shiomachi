# 潮待ち — 弁才船で瀬戸内を渡る

江戸時代の千石船（弁才船）を操って、瀬戸内の島々のあいだを港から港へ渡るブラウザのゲームです。
three.js で動きます。写真・動画・手描きのテクスチャ・既製の3Dモデルは使っていません。
船と港町は Python で Blender を動かして板1枚ずつ組み、木目・風化・陰を焼き付けました。島は数値の浸食で削った地形です。海・空・霞・帆・航跡・音は実行時の計算です。

> 船は復元船の公開資料と写真をもとにした作図で、実測図ではありません。島と港は架空です。

## 遊び方
朝の大島の浦から、島々のあいだを抜けて向島の浦へ向かいます。海面の暗い帯（風の強い所）と潮の流れを読み、日が暮れる前に錨を入れて一日を終えます。

| キー | 内容 |
|---|---|
| A / D | 舵（船足がないと効かない） |
| W / S | 帆を上げる・下げる |
| Q / E | 帆の向き（手で合わせるとき） |
| T | 船頭まかせ（帆の向きを自動で合わせる）の入り切り |
| R | 櫓（港の中や凪のとき、ゆっくり進む） |
| Space | 錨を入れる・上げる |
| C | 視点（後ろ・艫の上・遠望） |
| ドラッグ・ホイール | 視点を回す・寄る |

時刻は実時間1秒でゲーム内20秒進みます（1時間＝3分）。URL に `?t=16.5`（開始時刻）、`?wind=8`（風速 m/s）、`?wdir=0.9`（風向）、`?ts=60`（時間の速さ）を付けて変えられます。

## できるもの
- **船**：全長約30m、帆柱27m、25反の横帆。外板3段の段差、菱の象嵌が並ぶ垣立、水押、艫の大舵、船梁の頭、釘の列、畳んだ弥帆、伝馬船、碇と綱、米俵。板1枚ごとに色味と風化が違う
- **帆**：見かけの風で膨らみ、風に近すぎると震える。反ごとに違う布、継ぎ当て、縦綱、しわ。逆光では布が透け、縫い目が濃く見える
- **海**：16本のうねりと風浪（画面と船の浮力で同じ式）、風の帯に合わせて立つ40本のさざ波、太陽のきらめきと光の道、船と島の映り込み、船底の透け
- **航跡**：船のまわり127m四方の水面を GPU で解く（分散のある波の式なので V 字の引き波が出る）。舳先から2本の泡の筋
- **潮**：12.4時間周期の満ち引き。瀬戸では速く流れ、流れの縁に潮目が出る。船は流される
- **景色**：瀬戸内らしい丸い花崗岩の島、松林、岩の磯、浜、段々畑。港町の町家・蔵・雁木・常夜灯・波止。遠くには本州と四国の山並み
- **霞**：高さとともに薄くなる霞、太陽側の前方散乱、地球の丸み（20km先で約27m沈む）。遠い島ほど空の色に溶けて、層になって見える
- **時刻**：朝から夜まで太陽・空・霞・影・水の色がつながって変わる。日が暮れると常夜灯と船の提灯が灯る
- **音**：波、舳先の水切り、索具の風、帆のはためき、船体のきしみ、鴎、夕方の鐘（すべて WebAudio の合成）

## 動作環境
- 遊ぶだけ：WebGL2 が動くブラウザ（Chrome / Safari / Edge）。Apple M 系の Mac で快適に動きます。重いときは描画解像度が自動で下がります
- 焼き直し：Blender 5.x、Python 3.10+、cwebp

## 使い方
```sh
make serve       # http://127.0.0.1:8793/ で開く
make setup       # 焼き直しと確認用の Python 環境（numpy・scipy・Playwright）
make bake        # 船・港町・島を焼き直す（船 約5分、港 約3分、島 約4分）
make preview     # 船だけを Cycles で数方向から描いて確かめる
```

## しくみ
- **船の組み立て**（`bake/shipgeo.py`・`shipparts.py`）：船体は4本の縁の曲線（航の縁と3段の棚の上端）から、板を1枚ずつ厚みのある形で作る。継ぎ目は数 mm の隙間、釘は小さな金物として置く。垣立・屋倉・舵・帆柱なども同じ部品の組み合わせ
- **焼き付け**（`bake/ship.py`）：木目・日焼けの灰色・雨筋・水線の苔・タールをノードで作り、色・粗さ・AO を 4096² に焼く。UV は部品ごとに自分で与え（板は長さ×幅のまっすぐな長方形）、必ず別の島にしてから詰める
- **浮力と帆走**（`web/src/boat.js`）：船底を48断面×6列の柱に分け、柱ごとに水面より下の体積で浮力をかける。質量は設計の水線での排水量。帆は見かけの風への迎え角から揚力と抗力、舵は流速の2乗で効く
- **波**（`web/src/waves.js`）：Pierson–Moskowitz のスペクトルから風浪を、別に長いうねりを2本。Gerstner の式を GLSL と JS に同じ形で持つ
- **航跡**（`web/src/wake.js`）：Tessendorf の iWave。鉛直微分を 9×9 の畳み込みで入れて、長い波ほど速い分散を出す
- **霞**（`web/src/sky.js`）：透過率 exp(−∫β ds)、β は高さの指数関数。霞の色は水平線の空の色と太陽側の Henyey–Greenstein 散乱
- **島**（`bake/islands.py`）：複数の塊を座標の歪みで崩した島に、稜線のノイズと雨粒の浸食。港と瀬戸の位置は生成した海岸から決める

## 構成
```
bake/
  shipgeo.py      船体の線図（縁の曲線・断面・水押・艫板）
  shipparts.py    船の部品（外板・船底・垣立・帆柱・屋倉・舵・帆桁…）
  meshb.py        部品を集めて Blender のメッシュにする（UV つき）
  ship.py         材質・確認用の描画・焼き付けと書き出し
  port.py         港町の部品（町家・蔵・常夜灯・雁木・波止）
  islands.py      島と遠景の高さ（numpy）
  terrainlib.py   ノイズと浸食（灰の道から）
  blib.py         Blender の小道具（灰の道から）
web/
  index.html      ページと画面表示
  src/main.js     起動と1コマの流れ
  src/ship.js     船・帆・綱・提灯     src/boat.js    船の物理
  src/ocean.js    海面                 src/waves.js   波
  src/wake.js     航跡                 src/tide.js    潮
  src/wind.js     風の帯               src/sky.js     空・霞・太陽の位置
  src/islands.js  島                   src/trees.js   松
  src/port.js     港町                 src/audio.js   音
  src/shadows.js  影                   src/post.js    仕上げ（灰の道から）
  data/           焼いたデータ（glb・webp・高さ）
tools/probe.py    Chrome で開いて操作し、状態と画面を記録する
```
